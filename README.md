## About this data pack

Anytag 9minecraft Data Pack is a labelling tool for worlds that have outgrown memory. It adds a single craftable item whose whole job is to write one line of text and leave it floating beside whatever you point it at, so a base can explain itself without a single sign nailed to a wall. You make one from a name tag and a sign of any wood, give it a name on an anvil, and right-click the block you want it to describe. The item is spent and the words stay behind, hanging in the air in front of the block.
